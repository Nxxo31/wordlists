# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us as described below.

### How to Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to **sebastian@nxxo.dev**.

You should receive a response within 48 hours. If you do not receive a response, please follow up to ensure your message was received.

### What to Include

Please include the following information in your report:

- A description of the vulnerability and its impact
- Steps to reproduce the issue
- Any affected versions
- Possible remediation or mitigation suggestions

### Response Timeline

| Action | Expected Response Time |
|--------|----------------------|
| Acknowledge receipt | Within 48 hours |
| Initial assessment | Within 5 business days |
| Remediation or mitigation | Depends on severity |

### Scope

The following are considered in scope:
- Security vulnerabilities in the latest released version
- Security vulnerabilities in the main development branch

The following are **out of scope**:
- Vulnerabilities in third-party dependencies not directly caused by this project's code
- Social engineering attacks
- Physical security breaches
- Denial of service attacks against our infrastructure

### Disclosure Policy

- We will acknowledge receipt of your report promptly.
- We will investigate and provide an initial assessment within 5 business days.
- We will work with you to understand and remediate the issue.
- We will credit reporters in security advisories unless they prefer to remain anonymous.

## Supported Versions

| Version | Supported |
|--------|----------|
| latest | Yes |
| older  | No |

We only provide security updates for the latest version of the project.
