# Contributing

Thank you for your interest in contributing to this project! This document describes the process for submitting contributions.

## How to Contribute

1. **Fork** the repository to your GitHub account.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/REPO_NAME.git
   cd REPO_NAME
   ```
3. **Create a branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and commit them with clear, descriptive commit messages following [Conventional Commits](https://www.conventionalcommits.org/):
   ```bash
   git commit -m "feat: add new feature"
   git commit -m "fix: resolve issue with X"
   git commit -m "docs: update README"
   ```
5. **Push** your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request** from your fork to the main repository.

## Pull Request Guidelines

- Use the pull request template provided.
- Keep changes focused — one feature or fix per PR.
- Include a clear description of what changed and why.
- Ensure your code follows existing style conventions.
- Update documentation if needed.

## Reporting Bugs

- Use the bug report issue template.
- Include steps to reproduce the issue.
- Provide your environment details (OS, language version, etc.).

## Suggesting Features

- Use the feature request issue template.
- Describe the problem your feature solves.
- Provide examples of how it would be used.

## Code of Conduct

Participation in this project is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## Questions

Feel free to open an issue with the `question` label if you have any questions about contributing.
